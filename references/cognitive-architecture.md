# Cognitive architecture

## Bounded rationality

Humans are not expected-utility maximizers. Working memory is small, time is short, and the
brain spends roughly 20% of the body's metabolic energy — so it conserves. The default is
the cheapest sufficient answer, not the best one. Design for the cheap answer.

## Two systems

| | System 1 — intuitive | System 2 — deliberative |
| --- | --- | --- |
| Style | Automatic, associative, fast, emotional | Controlled, rule-governed, slow |
| Cost | Low effort | High effort; depends on working memory |
| Job | Produces the default impression | Audits that impression, hunts counter-arguments |
| Sells to it with | Salience, emotion, familiarity, fluency | Evidence, trade-offs, logical consistency |

System 2 does not run on most decisions. When it is under load — fatigue, time pressure,
information overload, an unfamiliar domain — it defers to whatever System 1 produced.

## Reading the load

Ask what the audience is doing in the moment of decision:

- **High load** (scrolling at midnight, comparing five plans, a stressed buyer): shorten the
  path. One recommended option, one number, one next step. Fluency reads as truth.
- **Low load** (a considered purchase, an evaluation committee): the shortcut backfires. Give
  the trade-off table, the evidence, the caveat. Hiding the weakness costs credibility here.

The same message cannot serve both. Diagnose before drafting.

## Choice architecture

- **Three options at most.** Two is a choice; three is a comparison with a middle; five is a
  decision to postpone. Beyond three, the difficulty of choosing displaces the value of the
  choice.
- **A named default.** Most people take the pre-selected path. Make the default the option
  you would defend out loud.
- **Fluency is a property of the sentence.** Short words, concrete nouns, active voice, a
  familiar structure. What is easy to read is judged as more true and more safe.
- **Salience beats completeness.** What the eye lands on first sets the frame. A correct
  detail buried below the fold has not been communicated.

## Diagnostic questions

- What else is competing for attention at the moment of decision?
- What is the one sentence they will repeat to a colleague?
- Which decision here is genuinely hard, and which difficulty is invented by the format?
